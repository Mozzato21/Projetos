# 🤖 InvestGuia - Assistente Virtual de Investimentos

[![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/)

O **InvestGuia** é um assistente virtual criado para o desafio do Lab DIO. A sua missão é ajudar pessoas a entenderem o mercado financeiro, comparando produtos de investimento (CDB, Tesouro, LCI/LCA, FIIs) e identificando o seu perfil de risco.
